# Meal Planner Client

React frontend built with [Vite](https://vitejs.dev/) and TypeScript.

## Available Scripts

### `npm start`

Runs the app in development mode using Vite.\
Open [http://localhost:5173](http://localhost:5173) to view it in the browser.

The page will hot-reload on edits.

### `npm test`

Runs the test suite with [Vitest](https://vitest.dev/).

### `npm run build`

Type-checks with `tsc` and builds the app for production to the `dist` folder.

### `npm run preview`

Serves the production build locally for preview.

## Tech Stack

- **React 18** with TypeScript
- **Vite** for bundling and dev server
- **Vitest** for testing
- **MUI (Material UI)** for UI components
- **React Router v6** for routing
- **styled-components** / Emotion for styling
- **@react-oauth/google** for Google OAuth
